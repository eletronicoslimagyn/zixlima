🌐 Conectar um modelo de IA

Compatível com APIs de conversa no formato OpenAI. Você escolhe o provedor, o modelo e a chave. Serviços gratuitos podem ter cotas; alguns exigem pagamento.

Segurança: use somente chaves com limite de gastos e permissões mínimas. Chamadas diretas do navegador expõem sua chave ao serviço de destino; nunca coloque chave secreta administrativa do GitHub, Supabase ou de terceiros aqui. Seu histórico não é enviado até você clicar em Enviar. Nem toda API aceita chamadas feitas de arquivos locais (CORS).

Também é possível apontar para um servidor local compatível, como http://localhost:11434/v1/chat/completions, desde que seu servidor aceite CORS e esteja ativo. O arquivo HTML sozinho não instala modelos no celular.

💾 Instalar e clonar em vários dispositivos

Use o arquivo index.html diretamente ou os instaladores incluídos no pacote ZIP. O programa continua portátil. Para chamadas de IA com menos restrições de navegador, execute o servidor Python local.

📦 Clonar para pen-drive, HD ou SD

Copie a pasta do pacote para uma unidade de armazenamento. Use o menu Clonar do instalador de seu sistema. Depois exporte seus projetos JSON abaixo e copie o backup para a mesma unidade. Não sobrescrevemos partições nem apagamos arquivos existentes.

Atenção: copiar o programa não cria uma mídia de inicialização do Windows/Linux. Um pen-drive bootável exige ISO e ferramenta específica (ex.: Ventoy/Rufus), com confirmação do disco de destino.

  1. Android rápido: abra index.html com o navegador (limitado ao armazenamento desse navegador).
  2. Android + Termux: extraia o ZIP e execute bash instalar.sh; escolha 1 para instalar ou 2 para iniciar.
  3. Windows: extraia o ZIP e execute INSTALAR_WINDOWS.cmd (Python 3 instalado para modo servidor).
  4. Linux: extraia e execute bash instalar.sh.
  5. Clonar: no instalador escolha opção 3 e informe uma pasta em uma unidade externa montada.

O backup é necessário porque a memória local do navegador não acompanha uma simples cópia do HTML.

Sem internet, chat generativo não funciona; editor, projetos, código, conhecimento e backups continuam acessíveis.

🧰 O que este programa realmente faz

É uma interface portátil leve para trabalho com IA: organiza projetos, códigos, conversas, memória e backups. Respostas avançadas dependem de um modelo remoto ou de um servidor local já instalado.

Para obter soluções complexas: conecte uma API compatível com conversa; escolha um modelo capaz de programação; cole código na aba Código; e use "Revisar código".

Sem conexão: ainda funciona como editor, organizador de projetos, anotações e exportador de arquivos, mas não gera respostas inteligentes por conta própria.

Internet: abrir páginas não significa que a IA tenha navegação na web. Na aba Pesquisa, o servidor local pesquisa fontes externas; o HTML sozinho não contorna restrições CORS.

Privacidade: projetos ficam salvos no armazenamento local do navegador, que pode ser apagado ou bloqueado no modo arquivo. Faça backup. Se usar IA externa, mensagens e documentos relevantes vão para o provedor escolhido.

Imagens e vídeos: esta versão concentra-se em programação e conhecimento. Produz storyboard, prompts e vídeos de prévia WebM a partir de cenas e imagens. Vídeos cinematográficos generativos exigem plataforma externa de vídeo por IA.
